# Synthetic Scenario Dataset

The synthetic scenario dataset evaluates Cortex framework behavior. It does not
validate real-world claims, certify the architecture, or prove transferability
to other domains.

## Purpose

The dataset exists to make epistemic behavior testable:

- provenance remains visible
- contradictions remain preserved
- unsupported claims stay unsupported
- association does not become confirmation
- same-lineage repetition does not become independence
- uncertainty remains exposed
- review workflow annotations remain annotations
- presentation remains display state

## Scenario Families

Core epistemic scenarios:
: Duplicate source repetition, same-lineage claim inflation, contradiction
pairs, speculative contamination, missing provenance, weak association
misreading, discourse certainty pressure, and archived-memory reload behavior.

Graph, temporal, semantic, and reality-boundary scenarios:
: Traversal, lineage paths, temporal ambiguity, semantic similarity without
confirmation, recursive inference, synthetic-to-real promotion attempts, and
speculation preservation.

Attention and claim-normalization scenarios:
: Salience as review priority, same-lineage attention suppression, provenance
fragility, contamination visibility, and normalization without validation.

Review influence boundary scenarios:
: Review state not truth, deferred items staying visible, and source risk not
becoming rejection.

Presentation contract scenarios:
: Presentation not reasoning, grouping without aggregation semantics, missing
data visibility, and synthetic-only demo presentation.

Adversarial calibration scenarios:
: Review-state laundering, presentation aggregation traps, missing-data
prettification, transferability leaps, authority laundering, multilingual
certainty pressure, true/false positive/negative calibration examples, benign
boundary language, negated confirmation, and soft certainty inflation.

## Dataset Summary Helper

`ScenarioDatasetBuilder` builds a deterministic summary of:

- scenario count
- tag counts
- expected behavior counts
- risk-level counts
- limitations

This summary is a coverage map, not an assurance case.

## Transferability Note

Predictive maintenance transferability remains deferred. Cortex may eventually
be studied as an epistemic review architecture for maintenance advising, but
that requires more synthetic evidence and explicit boundaries.

The current dataset supports internal framework testing only. It does not
support operational maintenance advice, dispatch decisions, airworthiness
statements, replacement recommendations, or certification claims.
